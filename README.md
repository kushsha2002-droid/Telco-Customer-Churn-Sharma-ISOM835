# Telco Customer Churn Prediction – ISOM 835

## Project Overview
This project applies predictive analytics and machine learning techniques to predict customer churn in the telecommunications industry. The analysis follows the full workflow from EDA and preprocessing to model evaluation and business recommendations.

## Objectives
- Identify key drivers of customer churn
- Build and compare machine learning models
- Evaluate models using appropriate classification metrics
- Translate technical results into actionable business recommendations
- Reflect on ethics and responsible AI considerations

## Dataset
- **Source:** Kaggle – Telco Customer Churn
- **Observations:** 7,043 customers
- **Target:** Churn (Yes/No)

## Tools & Libraries
Python 3, Google Colab, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, GitHub
